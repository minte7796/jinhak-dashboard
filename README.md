# 2027학년도 수시모집 스마트 경쟁률 대시보드

진학사 스마트 경쟁률([apply.jinhakapply.com/SmartRatio](https://apply.jinhakapply.com/SmartRatio)) 및 각 대학교 공식 원서접수 시스템(진학어플라이 / 유웨이어플라이)과 실시간 연동되어 주요 6개 대학/전형/학과의 실시간 수시 경쟁률을 모니터링하고 분석하는 웹 대시보드입니다.

---

## 🎯 모니터링 대상 대학 및 전형/학과

1. **광운대학교** : 학생부교과 (지역균형전형) - 컴퓨터정보공학부
2. **경기대학교** : 학생부교과 (학교장추천전형) - 산업경영공학과
3. **단국대학교** : 학생부교과 (지역균형전형) - 소프트웨어학과
4. **가톨릭대학교** : 학생부교과 (지역균형전형) - 데이터사이언스학과
5. **한경국립대학교** : 학생부교과 (일반전형) - 인공지능학과
6. **한국공학대학교** : 학생부교과 (지역균형) - 인공지능학과

---

## 🚀 주요 기능

- **앱 실행 시 자동 최신화**: 대시보드가 로드될 때 즉시 각 대학 공식 페이지의 최신 데이터를 수집하여 표시합니다.
- **대학별 최종 업데이트 시간 표시**: 각 대학 공식 원서접수처에서 발표한 공식 공시 일시(예: `2026년 09월 09일 23:50 기준`, `2026-09-09 오후 11:50 현재` 등)를 카드와 표에 명확히 표기합니다.
- **공식 경쟁률 페이지 바로가기**: 각 대학 카드 및 표에서 한 번의 클릭으로 해당 대학의 실시간 공식 경쟁률 페이지로 바로 이동할 수 있습니다.
- **수동 업데이트 버튼**: 상단 [지금 업데이트] 버튼 클릭 시 실시간으로 데이터 변경 사항이 있는지 조회하고 즉시 갱신합니다.
- **자동 갱신 주기 설정**: 1분, 3분, 5분 또는 끄기 옵션을 통해 원하는 주기로 자동 갱신할 수 있습니다.
- **증감(Diff) 추적**: 이전 수집 시점 대비 지원 인원 변동(+N명)을 실시간으로 추적 및 뱃지로 안내합니다.
- **경쟁률 시각화 차트**: Chart.js 기반 막대 차트를 통해 6개 학과의 경쟁률을 시각적으로 비교할 수 있습니다.
- **종합 KPI 요약**: 총 모집인원, 총 지원인원, 전체 평균 경쟁률, 최고 경쟁률 학과 요약 카드 제공.

## 💻 실행 방법

### 방법 1: 윈도우 원클릭 실행 (가장 간편)
- `run.bat` 파일을 더블 클릭하면 브라우저가 열리며 대시보드가 즉시 실행됩니다.

### 방법 2: 명령 프롬프트 / 터미널에서 실행
```bash
cd c:\gemini-app\temp
python app.py
```
브라우저에서 `http://127.0.0.1:5000` 접속
